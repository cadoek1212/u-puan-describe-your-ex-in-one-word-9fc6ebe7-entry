One word describing an ex, for make.fun's "Describe Your Ex in One Word"
bounty: **Recalled** — the ex as a product the manufacturer pulled back
for a defect. Not a plain insult, but a verdict with a twist: the maker
itself admitted something was wrong with them.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single word
`Recalled` (8 characters, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` in the grader).
No network, no clock, no randomness: two runs are byte-identical.
